# 图像去噪实时演示

这是一个面向《信号与系统》课程展示的本地交互式程序。用户上传图片后，程序会实时添加噪声、执行去噪算法、展示 DFT 频谱与滤波响应，并在有干净参考图时计算 MSE、PSNR、SSIM。

## 功能

- 上传任意图片作为原图，或上传已含噪图片并跳过加噪
- 实时添加高斯噪声、椒盐噪声、斑点噪声、混合噪声、周期噪声
- 空域滤波：均值滤波、中值滤波
- 频域滤波：理想低通、高斯低通、巴特沃斯低通、切比雪夫 I 型、切比雪夫 II 型、椭圆低通、带阻滤波器、自动带阻滤波器
- 保边滤波：双边滤波
- 高级去噪：非局部均值 NLM
- 自动优化滤波参数：有参考图时用 SSIM 网格搜索，无参考图时使用噪声类型启发式参数
- 展示原图频谱、含噪图频谱、频域滤波后频谱、频域响应、灰度直方图、边缘图
- 自动带阻会分别分析频域 x 轴、y 轴剖面和穿过中心的斜向亮线，寻找异常频率并生成对应带阻响应；斜向亮线检测阈值可手动调节
- 有参考图时显示 MSE、PSNR、SSIM；无参考图时改用视觉分析
- 一键演示矩阵：对同一上传图像实时生成多组噪声和算法对比

## 运行

建议使用 Python 3.12。Streamlit Community Cloud 部署时，在 Advanced settings 里选择 Python 3.12，避免 Python 3.14 与 SciPy / scikit-image 等图像科学依赖出现二进制导入兼容问题。

```powershell
streamlit run app.py --browser.gatherUsageStats=false
```

如果缺少依赖：

```powershell
pip install -r requirements.txt
```

## 展示建议

1. 先上传一张边缘和纹理比较明显的图片。
2. 使用“高斯噪声演示”说明均值、频域低通、双边和 NLM 的差异。
3. 使用“椒盐噪声演示”突出中值滤波对脉冲噪声的优势。
4. 使用“周期噪声与带阻”展示 DFT 频谱中噪声分布和带阻滤波器的作用。
5. 打开“一键演示矩阵”，快速展示不同噪声场景下的实时计算结果。
