# 图像去噪实时演示

这是一个面向《信号与系统》课程展示的本地交互式程序。用户上传图片后，程序会实时添加噪声、执行去噪算法、展示 DFT 频谱与滤波响应，并在有干净参考图时计算 MSE、PSNR、SSIM。

## 功能

- 上传任意图片作为原图，或上传已含噪图片并跳过加噪
- 实时添加高斯噪声、椒盐噪声、混合噪声、横向周期噪声
- 空域滤波：均值滤波、中值滤波
- 频域滤波：高斯低通、巴特沃斯低通、巴特沃斯多组径向 Band-Stop、巴特沃斯成对陷波带阻滤波器
- 保边滤波：双边滤波
- 高级去噪：非局部均值 NLM
- 展示原图频谱、含噪图频谱、频域滤波后频谱、频域响应、灰度直方图、边缘图
- 频域滤波参数完全手动配置，径向 Band-Stop 与成对陷波带阻滤波器均支持多组手动参数
- 所有数值参数均可直接键入，便于按频谱亮点位置精确设置参数
- 支持一键导出当前参数 JSON，并在总 ZIP 中保存参数配置
- 频谱页会分析含噪图频谱并推荐合适的频域滤波器与候选参数
- 上传原图并由程序加噪时，可启用 BO 自动调参，自动应用并锁定调优后的参数
- 上传图像本身含噪时，可用 NIQE-like 无参考指标进行 BO 自动调参，参数保持可编辑
- 后处理锐化页支持从滤波结果中手动选择一张图片并执行 USM 非锐化掩膜
- 混合噪声支持先用中值滤波预处理，再交给其他滤波器
- 有参考图时显示 MSE、PSNR、SSIM；无参考图时改用视觉分析
- 顶部导航栏分为图像、频谱、灰度直方图、边缘、后处理锐化五个视图，切换视图不会影响侧边栏参数

## 运行

建议使用 Python 3.12。Streamlit Community Cloud 部署时，在 Advanced settings 里选择 Python 3.12，避免 Python 3.14 与 SciPy / scikit-image 等图像科学依赖出现二进制导入兼容问题。

```powershell
streamlit run app.py --browser.gatherUsageStats=false
```

如果缺少依赖：

```powershell
pip install -r requirements.txt
```

## 展示建议

1. 先上传一张边缘和纹理比较明显的图片。
2. 选择“高斯噪声”，手动配置均值滤波、频域低通、双边滤波和 NLM，说明不同方法的平滑与保边差异。
3. 选择“椒盐噪声”，手动配置中值滤波，突出中值滤波对脉冲噪声的优势。
4. 选择“周期噪声”和“Butterworth Notch Reject”，根据频谱中关于中心成对出现的亮点，增加一组或多组陷波点，手动调整每组 Δu、Δv、陷波半径、阶数和抑制强度，观察 DFT 频谱中周期条纹对应异常分布的变化。
5. 当异常能量呈同心圆环或径向频带分布时，选择“Butterworth Radial Band-Stop”，增加一组或多组中心半径与带宽参数进行手动带阻。
6. 在上传原图并由程序加噪的场景中，启用“自动调参”，展示 BO 如何利用 MSE、PSNR、SSIM 搜索参数；上传图像本身含噪时，展示 NIQE-like 无参考调参。
7. 从某个滤波结果中选择一张图片，进入“后处理锐化”页手动执行 USM，观察发糊结果的细节增强。

## 文件结构

- `app.py`：Streamlit 界面、参数组织、结果展示和下载
- `denoise_lab/noise.py`：噪声生成
- `denoise_lab/spatial.py`：均值滤波和中值滤波
- `denoise_lab/frequency.py`：频域响应和频域滤波
- `denoise_lab/spectrum_advisor.py`：频谱分析和频域滤波器推荐
- `denoise_lab/auto_tune.py`：BO 自动调参
- `denoise_lab/no_reference.py`：NIQE-like 无参考质量评价
- `denoise_lab/sharpening.py`：USM 后处理锐化
- `denoise_lab/advanced.py`：双边滤波和 NLM
- `denoise_lab/analysis.py`：频谱、边缘、直方图和参考指标
- `denoise_lab/image_io.py`：图像格式转换
- `doc/guide.md`：指标解释、滤波公式和自动调参说明

## 代码说明

### 主程序流程

`app.py` 是 Streamlit 入口文件，负责把上传图像、噪声参数、滤波方法、结果展示和下载功能串起来。程序的核心流程如下：

1. 读取用户上传图片，调用 `denoise_lab/image_io.py` 将 PIL 图像转换为 `[0, 1]` 范围内的浮点 RGB 数组。
2. 根据侧边栏噪声场景调用 `denoise_lab/noise.py` 生成当前含噪输入；如果用户选择“无：上传图像已含噪”，则直接把上传图作为待处理输入。
3. 根据用户选择的方法依次调用空域、频域、保边和高级去噪模块，统一把输出保存到结果字典中。
4. 在“图像、频谱、灰度直方图、边缘、后处理锐化”五个视图中复用同一批结果，避免不同页面重复计算造成口径不一致。
5. 将原图、含噪图、滤波结果、频谱图、频域响应、指标 CSV、直方图 CSV 和参数 JSON 打包为 ZIP，便于复现实验。

### 算法模块

- `noise.py`：实现高斯噪声、椒盐噪声、混合噪声和横向周期噪声。随机过程由用户输入的种子控制，便于课堂演示时复现实验。
- `spatial.py`：实现均值滤波和中值滤波。彩色图像按通道分别处理，最后裁剪回 `[0, 1]`。
- `frequency.py`：实现高斯低通、巴特沃斯低通、多组径向 Band-Stop 和成对陷波带阻滤波器。频域滤波流程为 FFT、中心化、乘以响应函数、逆 FFT 和结果裁剪。
- `advanced.py`：封装双边滤波和 NLM。双边滤波用于保边平滑，NLM 利用相似图像块进行非局部去噪。
- `sharpening.py`：实现 USM 非锐化掩膜。该模块只在用户手动点击后处理锐化按钮后执行，不会自动改变原滤波结果。

### 分析与调参模块

- `analysis.py`：提供灰度转换、DFT 幅度谱、Canny 边缘图、灰度直方图、轴向频谱和 MSE / PSNR / SSIM 参考指标。
- `spectrum_advisor.py`：根据含噪图频谱查找异常亮点、径向能量峰和高频能量，给出频域滤波器与候选参数建议。建议只作为初值，周期噪声场景仍以手动观察频谱并设置陷波点为主。
- `auto_tune.py`：实现自动调参。参考图已知时使用 `SSIM + PSNR / 60 - min(25 * MSE, 2)` 作为目标分数；上传图像本身已含噪时使用 NIQE-like 无参考质量评价。
- `no_reference.py`：实现轻量 NIQE-like 指标，通过 MSCN 统计、梯度和对比度估计无参考图像质量。

### 依赖说明

项目运行依赖集中在 `requirements.txt`。当前源码实际使用的第三方库包括：

- `streamlit`：交互式 Web 界面
- `altair`、`matplotlib`：图表、频域响应和可视化
- `pandas`：指标表、直方图和 CSV 导出
- `numpy`、`scipy`、`scikit-image`：核心图像处理、频域分析和评价指标
- `pillow`：上传图片读取和下载图片编码
